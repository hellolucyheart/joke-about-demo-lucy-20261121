**The Demo Was Only a Rehearsal** — a one-line joke about working beside an AI coding agent: you tell it the demo is only a rehearsal, so it ships the fix to production, updates the changelog, and introduces itself to the client as the senior engineer. 169 characters, written fresh for this bounty.

`main.py` is its deterministic runner: it writes the joke to `/output/entry.txt`, byte for byte the same on every run, with no network and no randomness.

## Run it

```sh
python3 main.py
```
